# 景德镇市妇幼保健院儿童保健康复为残障儿童托起康复梦想

> 更新时间：2026-09-17 (UTC+8)

**“来，放松，放松，伸……、屈……”******

**“用力，自己来，加油，不哭，加油，真棒，真棒……”******

**伴随着一阵阵孩子们的哭声、笑声和治疗师时不时发出的口****令，**

**划破了清晨的宁静，**

**同时也开始了景德镇市妇幼保健院儿童保健康复治疗师们一天的繁忙工作。**********

****

****

这是景德镇市妇幼保健院的一个特殊的科室，走进去一看，墙上贴满了各种卡通贴画，还有各式各样的小玩具，不知道的还以为走进了幼儿园，这就是残障儿童康复治疗的场所。在孩子们的心里早就把康复中心当成了幼儿园。因为长年累月的持续康复治疗，他们就在这里逐渐长大，这里有他们的童年，这就是他们的家。

这里有一群特殊的孩子，因为诸多的原因，导致无法与正常的小孩一样拥有正常的运动能力、语言能力和思维能力。不能独坐、不会行走、不会说话和智力低下，是他们典型的临床表现，也是他们最大的功能障碍。

这里有一个特殊的团队，我们被行业称为康复治疗师。之所以特殊，是因为康复治疗师不同于临床医师，我们是康复医嘱的执行者，我们又是康复治疗方案的制定者，我们为每一位患儿进行一对一的康复训练。****

康复治疗师主要负责肢体功能康复训练。根据每个孩子不同的治疗方案，我们所做的每一个动作都是有针对性的。设定近期目标和远期目标，通过设定小目标，再细化到具体动作，直到完成目标，达到预期的治疗效果。

****

****

**绝不心软，严格要求**

前来治疗的孩子，大多数属于四肢肌张力增高的痉挛型。治疗师通过按、压、揉、捏、牵拉等康复手技，达到降低患儿肌张力的目的。然而牵拉肌肉给患儿带来的剧烈疼痛，往往会让他们感到撕心裂肺，刚开始家长很担心，随着治疗的深入，患儿不断的进步，他们个个都很放心。他们表示，治疗师严格要求，虽然给孩子带来了一定的痛苦，但也是为了孩子将来能少受点苦，现在多流泪就是为了以后少流泪。孩子一天天的进步和家长慢慢的理解，给了我们努力的动力和继续“狠”下去的决心。

**体力透支，痛并快乐**

治疗师长时间在软垫上弯腰盘膝而坐，徒手为患儿进行康复训练，一天下来腰酸肩膀痛，这是常事；训练过程小孩遗尿、吐奶、呕吐物把衣服浸湿的事也时有发生。即便如此，我们也没有退缩，我们一直保持一颗仁者之心，以爱心、耐心、细心、责任心去理解他们、包容他们、守护他们，这是我们作为一名合格康复治疗师最基本的素质要求。看到孩子们一天一天的进步，从一开始不会翻身抬头，到能独坐爬行，直至最后的行走和跑跳，所有的辛勤付出都是值得的，那种开心和成就感，是无法用语言来表达的。

**亦师亦友，心灵沟通**

走进孩子的内心，我们既是孩子的治疗老师，又是孩子的大朋友。用我们的爱心，温暖孩子；用我们的真心，照亮孩子。内心的有效沟通，与孩子有了感情基础，孩子们更愿意和我们在一起，在游戏中训练，在训练中进步，争取孩子主动参与康复训练，是我们一直追求的治疗模式，也更能达到预期的治疗效果，让孩子最大程度得到康复。

即使我们的康复训练可能无法让这群孩子完全恢复到与正常孩子一样，但我们所付出的努力也许可以帮助这群孩子将来能够生活自理，最大限度地减少他们和正常小孩之间的差距，为他们燃起康复的希望，让他们健康快乐地成长。
